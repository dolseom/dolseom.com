Ask the way you already talk to Claude

No company name or API key is needed for duty, deadline and fine checks. Claude picks the right tool.

"Our unlisted affiliate approved an 8.0B KRW loan to another affiliate. Total equity is 120B KRW. Do we have to disclose it, and by when?"

"비상장 계열사에 80억 자금대여 의결했어 (자본총계 1,200억). 공시 대상이야? 기한은?"

Disclosure is required. The threshold is 6.0B KRW, which the 8.0B KRW transaction exceeds. Deadline: 7 business days after the board resolution (unlisted). Basis: Large-scale Internal Transaction Notice §6①.

threshold = min(10B, max(0.5B, equity 120B × 5%)) = 6B ≤ 8B

"We filed a 3.0B KRW internal-transaction disclosure 5 days late. What is the expected fine?"

"30억 내부거래 공시를 5일 늦게 냈어. 과태료 얼마 나와?"

Expected 1.65M KRW, with the full formula. If the amount is unknown, the answer is labeled as an upper bound instead of a silent guess.

(base 5.0M + day add-on 0.5M) × 60% (2B–4B bracket) = 3.3M − 50% (≤7 days late) = 1.65M

"We missed the deadline 3 days ago and still haven't filed. What changes if we file now?"

"기한 놓친 지 3일째인데 아직 공시 전이야. 지금 내면 뭐가 달라져?"

The voluntary-correction window (10 business days after the deadline) is still open. You get its end date, remaining business days and exemption conditions.

Why it can be trusted

In disclosure work, confident answers without evidence are worse than wrong ones.

Statutes, not folklore

Common claims like "file within 1 day" or "the 5B KRW threshold" are outdated. Every answer carries the provision, formula and inputs so the officer can re-check it.

Dates from verified calendars

Business days use 2026–2027 holiday data checked against official notices, including substitute holidays. Unverified years return a warning.

Never "nothing found" when unchecked

Truncated searches, failed reconciliations and unverifiable conditions are reported as such, not folded into "no issues".

Install

Requires Node.js 22.13 or later. Duty, deadline, fine and business-day checks work without any key.

# Claude Code
npx -y gongsi-mcp setup
claude mcp add gongsi-mcp -- npx -y gongsi-mcp
// Claude Desktop — claude_desktop_config.json
{
  "mcpServers": {
    "gongsi-mcp": {
      "command": "npx",
      "args": ["-y", "gongsi-mcp"],
      "env": { "DART_API_KEY": "your OpenDART key" }
    }
  }
}

Limits

  • Results are reference information based on statutes and official notices. They are not legal advice or an official KFTC interpretation.
  • Calculations and citations are verified, but Claude's final summary can drop a condition. Compare conclusions with the cited text.
  • Filing checks read filings already submitted to DART, not unsubmitted drafts.
  • No automatic filing. Judgment, evidence and drafts are the tool's job; submission stays with the officer.
